🏏 IPL Indian Player Performance Dashboard | Power BI

📌 Project Overview
This project presents an interactive IPL Cricket Performance Dashboard built using Microsoft Power BI. It focuses on analyzing Indian players who have played 50 or more matches.

🎯 Project Objectives
- Analyze player and team performance.
- Compare runs, boundaries, and strike rates.
- Explore season-wise and opponent-wise trends.
- Present cricket statistics through interactive visualizations.

📊 Dashboard Features
- Total Matches, Total Runs, Total Wickets, Total Fours, Total Sixes, and Strike Rate.
- Top 10 Players by Runs.
- Runs by Team and Season.
- Dismissal Type Analysis.
- Runs by Opponent.
- Fours vs. Sixes by Season.
- Matches Played by Season.
- Strike Rate by Season.
- Interactive Team and Season filters.

🛠️ Tools & Technologies
- Microsoft Power BI
- DAX
- Data Cleaning and Analysis
- Data Visualization

📂 Project Files
- `IPL_Player_Analysis.pbix` — Power BI report file.
- `dashboard_screenshot.png` — Dashboard screenshot.
- `README.md` — Project documentation.

🚀 How to Use
1. Download the `.pbix` file from this repository.
2. Open Microsoft Power BI Desktop.
3. Open the downloaded report.
4. Explore the dashboard using the available filters.
